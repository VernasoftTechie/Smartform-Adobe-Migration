# Client Naming Standards

The client's own object/field naming conventions and governance documents —
not Vernasoft's default naming (`docs/05_individual_form_conversion_framework.md`'s
`_ADT`/`_INT` convention, the Bolt Playbook §1.4 default). When the client has
a mandated prefix, namespace, or naming policy, it is recorded here, and it
**overrides** the Vernasoft default for every object built against it (Bolt
Playbook §1.5).

Place the client's own document(s) here as supplied (PDF, Word, Markdown,
whatever they provide) — do not transcribe or paraphrase into a new format.

**Current inventory:** none yet — populated once the client supplies a
naming standard document, via Bolt Console's Configure → Global reference
library, or a direct push here.
