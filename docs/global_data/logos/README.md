# Global SE78 Graphic Library

Place the one-time `P_GLOB` inventory here as `global_logos.txt`. Store each
approved original SE78 export using its SAP graphic name and retain a
sidecar provenance note when the filename alone cannot record object, ID,
type, source system/client, and export date.

For every reusable asset, record:

| SAP graphic | Object / ID / type | Adobe reference method | Status |
|---|---|---|---|
| _(populate after SAP export)_ | | | |

An Adobe form should use the verified SAP graphics-repository reference or
the approved exported asset. Never substitute a similarly named image.
