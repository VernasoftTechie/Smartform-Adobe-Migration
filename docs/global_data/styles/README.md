# Global SmartStyle Exports

Place the one-time `P_GLOB` inventory here as `global_smartstyles.txt`.
Store original SMARTSTYLES XML exports with their SAP SmartStyle name, for
example `ZSTYLE_PR_FORM.xml`.

For every reusable mapping, record:

| Source SmartStyle | Adobe style/pattern | Evidence | Status |
|---|---|---|---|
| _(populate after SAP export)_ | | | |

The approved mapping belongs in `docs/04_global_style_catalogue.md`; this
folder preserves the raw source evidence it is based on.
