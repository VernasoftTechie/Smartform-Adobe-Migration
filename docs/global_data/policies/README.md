# Client Policies & Instructions

General client-supplied policy or instruction documents that aren't a
naming standard specifically (see `../naming_standards/` for those) — e.g.
a sign-off/approval policy, a style preference note, a scope clarification,
anything the client wants followed across the whole engagement rather than
one migration.

Place the client's own document(s) here as supplied — do not transcribe or
paraphrase into a new format.

**Current inventory:** none yet — populated once the client supplies a
policy/instructions document, via Bolt Console's Configure → Global
reference library, or a direct push here.
