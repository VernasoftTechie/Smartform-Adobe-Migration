## Mandatory SAP-side Context action

After pulling the SFPI update, use SFP to add the four exceptions, activate
the interface, and use the Context tab's native generate/synchronize action
to expose the parameter/table nodes under the form. Then pull that
SAP-generated form serialization through abapGit. This is mandatory because
the Context is a linked `CL_FP_NODE` object graph generated by SFP; hand
constructing it cannot safely establish the SAP-internal node IDs and links
that XDP data bindings require.

Until that pull completes, leave the XDP unbound. No driver, NACE, or
cutover change belongs to this phase.
